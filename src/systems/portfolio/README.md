# Portfolio Management System (PMS)

The Portfolio Management System is a sophisticated financial management platform designed to optimize and manage Equihome's loan portfolio. It provides comprehensive tools for portfolio analysis, risk assessment, scenario simulation, and performance tracking.

## Quick Start

```bash
# Start the development server
npm run dev

# Run tests
npm test
```

## System Overview

The Portfolio Management System:

1. **Tracks Portfolio Performance**: Monitors key metrics and performance indicators
2. **Simulates Scenarios**: Runs financial simulations based on Traffic Light System data
3. **Optimizes Allocation**: Provides recommendations for optimal portfolio allocation
4. **Analyzes Risk**: Evaluates portfolio risk and diversification
5. **Forecasts Returns**: Projects future returns and cash flows

## Key Features

- **Portfolio Dashboard**: Comprehensive overview of portfolio performance
- **Simulation Engine**: Advanced financial modeling and scenario testing
- **Fund Parameters**: Configurable settings for portfolio management
- **Analytics**: In-depth analysis of portfolio metrics and trends
- **Stress Testing**: Evaluate portfolio resilience under various market scenarios
- **Financial Modeling**: Sophisticated financial modeling tools for portfolio analysis
- **Data Visualization**: Interactive charts and graphs for data visualization
- **Export Capabilities**: Export portfolio data and reports in various formats

## Integration with Other Systems

The Portfolio Management System integrates with:

- **Traffic Light System**: Uses suburb classifications and risk assessments for portfolio optimization
- **Underwriting System**: Receives approved loans for portfolio inclusion

For detailed integration documentation, see the [API Integration Documentation](./docs/api/INTEGRATION.md).
