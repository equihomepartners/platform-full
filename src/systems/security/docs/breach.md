# Breach Response

## Overview

This document outlines the data breach response capabilities of the Equihome platform. These capabilities are designed to detect, assess, contain, and remediate data breaches in compliance with Australian regulatory requirements, particularly the Notifiable Data Breaches (NDB) Scheme under the Privacy Act 1988.
